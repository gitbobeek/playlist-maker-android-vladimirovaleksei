# 🎵 Playlist Maker

Android-приложение для поиска музыки, управления плейлистами и работы с избранными треками. Проект построен по принципам Clean Architecture с использованием MVVM, Jetpack Compose и современных библиотек экосистемы Android.

## 📖 Описание
Приложение позволяет:
- 🔍 Искать треки через **iTunes Search API** с автоматическим сохранением истории запросов
- ❤️ Добавлять треки в избранное
- 📁 Создавать, просматривать и удалять плейлисты, добавлять в них треки
- ⚙️ Настраивать параметры приложения (поделиться, поддержка, пользовательское соглашение)
- 💾 Локально сохранять данные с помощью **Room** и **DataStore**

## 🚀 Сборка и запуск

1. **Клонирование репозитория**
   ```bash
   git clone https://github.com/gitbobeek/playlist_maker_android_vladimirovaleksei.git
   cd playlist_maker_android_vladimirovaleksei
   ```

2. **Открытие в Android Studio**
   - Запустите Android Studio
   - Выберите `File → Open` и укажите папку с проектом

3. **Синхронизация зависимостей**
   - Дождитесь автоматической индексации Gradle
   - При появлении уведомления `Sync Now` нажмите на него для загрузки библиотек (Retrofit, Room, Coil 3, Compose и др.)

4. **Запуск приложения**
   - Подключите физическое устройство (Android 7.0+) или запустите виртуальный эмулятор
   - Нажмите кнопку `▶️ Run 'app'` в верхней панели IDE
   - Убедитесь, что устройство имеет доступ к интернету (для работы поиска через iTunes API)

## 📂 Структура проекта
```
├── data/                 # Источники данных (Room DAO, Retrofit, DataStore, Mappers)
├── domain/               # Интерфейсы репозиториев (абстракции)
├── presentation/         # UI на Jetpack Compose, ViewModel, Factory, Navigation
├── App.kt                # Инициализация глобальных сервисов (DB, DataStore)
└── MainActivity.kt       # Точка входа, хост навигации
```

## 📜 Примечания
- Проект не требует API-ключей: используется публичный iTunes Search API
- Отключение проверок CRL/OCSP в `App.kt` добавлено для предотвращения `SSLHandshakeException` при работе с серверами Apple на некоторых устройствах/эмуляторах
- Лицензия: учебный проект. Все права на музыку и обложки принадлежат правообладателям и Apple Inc.
